MONK MODE — 30 DAYS

GitHub Pages 公開手順:
1. GitHubでPublicリポジトリ monk-mode を作成
2. ZIPを展開し、中身のファイル6個をリポジトリのルートにアップロード
3. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save
4. 数分後 https://ユーザー名.github.io/monk-mode/ にChromeでアクセス
5. Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」

データはブラウザのローカルストレージに保存されます。ブラウザのデータ削除や端末変更で失われるため、定期的にアプリのバックアップ機能を使ってください。
公開リポジトリに個人の記録やバックアップJSONをアップロードしないでください。
